# ИС «Аварийно-диспетчерская служба» ООО «Водоканал-Сервис»

Учёт заявок аварийно-диспетчерской службы: приём заявок от населения, назначение бригад,
отключения водоснабжения, расход материалов, отчёты.

Разработал: Демидов Д.Ю., группа ИС.09.24.1, КГБПОУ «Канский технологический колледж», 2026.

## Состав

| Папка / файл | Что это |
|---|---|
| `VodokanalDispatch.sln` | решение Visual Studio (открывается в VS 2019 и новее) |
| `VodokanalDispatch/` | исходный код (C#, Windows Forms, .NET Framework 4.8) |
| `Database/VodokanalDispatch.sql` | скрипт создания базы данных со всеми таблицами, отчётами и тестовыми данными |
| `Database/VodokanalDispatch.bak` | резервная копия базы (восстанавливается в SQL Server 2022 и новее) |

## Учётные записи для проверки

| Логин | Пароль | Роль | Что может |
|---|---|---|---|
| admin | admin | Администратор | всё, включая пользователей |
| dispatcher | dispatcher | Диспетчер | заявки, справочники, отчёты |
| master | master | Мастер (Бригада АВР № 1) | только заявки своей бригады: статус, результат, материалы |

## База данных

Таблицы: `Districts`, `Streets`, `AccidentTypes`, `Brigades`, `Employees`, `Materials`, `Users`,
`Requests`, `RequestMaterials`, `Shutdowns`. Представление `RequestsView`.

Хранимые процедуры (отчёты):
- `ReportByTypeAndDistrict` — среднее время устранения по районам и типам аварий, доля просрочки норматива;
- `ReportTopStreets` — топ-10 аварийных улиц с затратами на материалы;
- `ReportBrigades` — загрузка бригад;
- `ReportByMonth` — количество аварий по месяцам.

Пароли хранятся в виде хеша SHA-256 (`HASHBYTES`), все запросы из программы параметризованные.
